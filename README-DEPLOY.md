# NewbieMail Eyewear — GitHub Pages deployment

This package is prepared for the repository `newbiemail/NewbieMail-Eyewear`.

Recommended GitHub Pages setup:
- Repository: `NewbieMail-Eyewear`
- Branch: `main`
- Folder: `/ (root)`
- Expected public URL: `https://newbiemail.github.io/NewbieMail-Eyewear/`
- Keep `.nojekyll` in the repository root.

Upload the **contents** of this folder to the repository root, not the outer folder itself.

The site is static. Cart and wishlist interactions are front-end experiences and no real payment, prescription, customer-account, or order backend is included.
