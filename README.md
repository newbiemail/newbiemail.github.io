# NewbieMail

**Modern Eyewear · Curated Discovery**

NewbieMail is an independent eyewear discovery experience that organizes selected designer optical and sunglass listings by brand, shape, material, size, and reference price.

> **See better choices. Compare clearly.**

---

## Website

This repository contains the static NewbieMail website for GitHub Pages.

### Included

- Premium responsive homepage
- Curated shop
- Sunglasses and optical collections
- Shape-based browsing
- Product detail pages
- Current reference prices
- Saved Frames using localStorage
- Source disclosure
- Privacy and terms pages
- SEO metadata, sitemap, robots.txt, web manifest, and `.nojekyll`

## Product Sources

The Designer Edit uses public product information and externally hosted product imagery from Designer Eyes. Products link directly to their original retailer listings. NewbieMail does not process these purchases and is not affiliated with Designer Eyes or the listed designer brands.

Prices and availability can change; the original retailer listing is the source of truth.

## Technology

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Deployment

For the GitHub user site repository `newbiemail.github.io`, upload the **contents** of this ZIP directly to the repository root and publish from `main` / `(root)`.
